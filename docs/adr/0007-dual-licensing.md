# ADR-0007: Dual licensing (AGPL-3 + търговски) на Matrix стека

- **Източник на реконструкцията:** memory `products/design_matrix/project_formula_eval_cleanroom_2026_06_11` (dual licensing секция), `topics/licensing/licensing_master_reference` §1, §6.2; git `product-design-properties` `e8f2e7f`/`c3e9687`/`057884a` (2026-06-12); root файлове `DUAL_LICENSING.md`, `LICENSE-COMMERCIAL.md`, `CLA.md`, `THIRD-PARTY-LICENSES.md`

## Контекст

Matrix стекът трябва да е едновременно отворен (за общност/доверие/reuse) и комерсиализируем (проприетарен пласт за платещи клиенти, освободени от AGPL задълженията). Правоносителят не е обвързан от собствения AGPL и може да лицензира и платено — но само след като веригата е чиста от чужд AGPL ([ADR-0006](0006-prenapisvane-formula-eval.md)) и правата са консолидирани (CLA).

## Разгледани алтернативи

1. **Само AGPL.** — Отхвърлено: не позволява проприетарен пласт/освобождаване на платещ клиент.
2. **Само проприетарен.** — Отхвърлено: губи отворената база и reuse.
3. **Dual: AGPL-3 + търговски лиценз.** — Прието.

## Решение

Целият PDP стек е dual (AGPL-3 + commercial): scaffolding в корена — `DUAL_LICENSING.md`, `LICENSE-COMMERCIAL.md` (ЧЕРНОВА), `CLA.md` (ЧЕРНОВА), `THIRD-PARTY-LICENSES.md` (точен MIT текст на ZEN); dual header на всеки `.py`/`.xml`; README бележка. Manifest `license` остава „AGPL-3" (Odoo няма dual enum). LICENSOR = Rosen Vladimirov. Предхождащо условие — нормализация на holder-а към Rosen Vladimirov (BL Consulting/OCA махнати; git `d404960`/`8dde606`/`8e097bd`, 2026-06-11).

## Обосновка

Dual моделът съчетава отворена база с комерсиализация. Работи само защото: (а) чуждата AGPL котва е махната ([ADR-0006](0006-prenapisvane-formula-eval.md)); (б) ZEN е MIT ([ADR-0003](0003-izbor-gorules-zen.md)); (в) правата се консолидират през CLA преди чужд принос.

## Последици

- Отвори пътя за проприетарни надстройки (T1/T2/T3) върху отвореното ядро.
- Наложи CLA gate за частните репа (виж l10n-bulgaria [ADR-0003] за CLA портата).
- Създаде зависимост от правен преглед: комерсиалните файлове са черни.
