Design parameter definitions and GoRules matrix templates for roller garage
door manufacturers.

Covers: galvanized / pre-lacquered / insulated / perforated steel slats;
torsion-spring manual and electric (side, overhead, smart-remote) drives;
standard and heavy-duty C-guide rails; optional side seals and wicket doors.

The matrix engine (T0–T3) validates opening dimensions, derives slat geometry
and guide rail weights, activates O-variant BoM lines for motor/seals/wicket
kit, and schedules operations (cutting, assembly, motor programming, QC).
