# Changelog

All notable changes to this module will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [18.0.1.1.0] - 2026-04-29

### Added

- Full T0/T1/T2/T3 matrix template for RSC (Regular Slotted Container).
  T0: non-zero dimension validation.
  T1: blank dimensions + flute_factor lookup by board_type (E/B/C/BC).
  T2: liner outer/inner and medium weights (kg) with inline area formula.
  T3: Score+Fold always; Flexo Print when has_print; Die-Cut when die_cut.

## [18.0.1.0.0] - 2026-04-01

### Added

- Initial module: design parameter definitions for Corrugated / Cartons industry.
