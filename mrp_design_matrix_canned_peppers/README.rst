Industry sub-module for canned roasted pepper manufacturers. Covers a
food-processing use case where the matrix drives brine composition,
sterilization time per container size, and labelling runs.

Parameters include pepper variety, jar volume (ml), fill method (whole /
sliced / strips), and sterilization profile. Demonstrates that the
matrix engine is not limited to assembly manufacturing — it handles
recipe-style BoMs with time-based operations (T3) just as well.
