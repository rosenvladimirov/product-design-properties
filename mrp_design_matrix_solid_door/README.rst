Design parameter definitions and matrix template for the SolidDoor
(portalsolid.com / MySolidDoor) product range.

Covers 18 door models (B Smart, Solid Alpha/Pulse, iDoor family,
mDoor family, Klasik EI60 fire-rated, Select) with configurable
coating, frame, slab, line, handle, lock and extras.

Depends on ``mrp_design_matrix``. Loads properties definition and a
single matrix template ``Solid Door — Standard``. Master BoMs link
to this template via ``action_load_from_template()``.
