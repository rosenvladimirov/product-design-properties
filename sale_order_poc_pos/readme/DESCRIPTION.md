Touch editor of the production configuration (POC) of a wholesale line in
the Point of Sale.

In the Order Lines of a wholesale order (module `l10n_bg_pos_b2b_sale`),
selecting a line whose product has a production configuration template
saves the order as a quotation and opens the configuration of the line in
the right pane of the Point of Sale: the parameters grouped by the sections
of the template, with large touch controls, and a "Save and compute" button.
The computed unit price of the quotation line goes back to the line of the
Point of Sale.
