Industry sub-module for security door manufacturers. Parameter set
covers RC class (RC1–RC4), sheet thickness, glass panel option, lock
configuration, and dimensions.

T0 constraints enforce minimum sheet thickness per RC class and block
glass panels on RC4. T1 geometry computes door weight and hinge count.
T2 material table drives panel layering and reinforcement strip
selection.
