Industry sub-module for interior door manufacturers. Parameter set
covers construction type (HDF, solid wood, glass), leaf type (single /
double), opening direction, finish type, and frame dimensions.

T0 constraints prevent incompatible combinations (e.g. glass
construction + soundproofing). T2 material table handles single vs
double leaf quantities, finish layering, and hardware kits.
