Industry sub-module for garbage bag manufacturers.  Provides a ready
parameter set (`bag_type`, `density`, `width`, `length`, `has_tie`,
`has_print`, …) and matching GoRules matrix templates so the
`mrp_design_matrix` engine can generate MOs for typical bag
configurations out of the box.

The module is installable as-is with demo data, or can be used as a
reference template for adapting the stack to other flexible
packaging products.
